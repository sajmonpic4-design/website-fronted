# Podsumowanie zawodów wędkarskich 🎣

Interaktywna strona internetowa służąca do podsumowywania wyników zawodów wędkarskich. Umożliwia wprowadzenie liczby złowionych ryb przez czterech zawodników, a następnie automatycznie oblicza łączną liczbę ryb oraz średnią przypadającą na jednego uczestnika.

Projekt wyróżnia się przyjaznym, tematycznym interfejsem, dopasowanym do wędkarskiego klimatu. Zastosowałem animowane elementy, pływające rybki, efekty interakcji oraz responsywny układ, dzięki czemu strona jest estetyczna i wygodna w obsłudze również na urządzeniach mobilnych.

**Wykorzystane technologie:**
- HTML5 – struktura strony.
- CSS3 – stylowanie, animacje, efekty wizualne i responsywność.
- JavaScript – dynamiczne elementy oraz interakcje użytkownika.
- PHP – przetwarzanie formularza i obliczanie wyników.

**Informacja o wykorzystaniu AI:**  
Bazowy styl wizualny strony został wygenerowany przy pomocy sztucznej inteligencji (AI), a następnie częściowo zmodyfikowany i dostosowany przeze mnie. Projekt obejmował również pracę nad funkcjonalnością strony, animacjami oraz integracją poszczególnych elementów.

**Cel projektu:** połączenie prostej funkcjonalności obliczeniowej z atrakcyjnym wyglądem i interaktywnym interfejsem użytkownika.
